# 🐸 Froggy Weather

A playful, responsive weather dashboard where Froggy reacts to the weather.

## Features
- Live current weather and 5-day forecast
- Search cities worldwide
- Use browser location
- Animated frog scene that changes for sunny, cloudy, rainy and nighttime conditions
- No API key required
- Pure HTML/CSS/JavaScript — no build step

Weather data: [Open-Meteo](https://open-meteo.com/)

## Run locally
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deployment
The repository includes a GitHub Pages workflow in `.github/workflows/deploy.yml`.
